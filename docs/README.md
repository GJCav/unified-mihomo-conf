# Project documents

One directory per change: `docs/<YYYY-MM-DD>-<slug>/`, dated by when planning
started. Copy the files in [templates](templates) to begin. Roles and the
workflow are in [AGENTS.md](../AGENTS.md).

- `plan.md`: requirements, final design, and steps
- `dev-log.md`: what was done, deviations, and review decisions
- `test-log.md`: what was run and what happened

Logs are append-only: correct an earlier entry with a new one.
